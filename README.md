## Welcome to OpenRSC: Reliving the Original RuneScape Classic!

OpenRSC is a community-driven project that has attempted to recreate the original RuneScape Classic (RSC) game, which closed down in 2018.

### What is OpenRSC?

* The original RSC was closed down and abandoned after nearly 18 years on August 6th, 2018.
* It's a passion project built through **reverse engineering and community effort**.
* From the inception of the Open RSC project in June 2018, the team has reviewed thousands of hours of RSC+ replays to ensure an accurate and authentic in-game experience.
* This project has been built upon the efforts of the RSC private server developer community spanning from 2006 to 2018.
* The core framework has been rewritten to be scalable and supports both the classic experience and **optional new features**.
* Included are several server configurations that allow many new game features to be activated without needing to change any code. Example: Runecrafting, custom sprites, faster game speeds, higher experience rates, new quests, auction house, clans, parties, pets, holiday events, and so much more.
* We operate this strictly as a **non-profit hobby** and host free-to-play public worlds.

### Running Your Own Server

If you want to host the game yourself, here is how you can get started:

#### Minimum Requirements
To run the game server, you will need:
* **1GB RAM**
* **Java Development Kit (JDK) 8 or newer**
* **Apache Ant** or **Gradle**
* **SQLite or MariaDB / MySQL**

You can download the latest Open JDK from:
* [Azul Zulu Builds of OpenJDK](https://www.azul.com/downloads/zulu-community/?architecture=x86-64-bit&package=jdk) (Windows users should select the MSI installer)
* [Adoptium Temurin JDK](https://adoptium.net/temurin/releases?version=21&os=any&arch=any)

#### How to Play Locally (Recommended First Step)
The team suggests running the game locally first to learn how everything works before hosting a public server.
* See the **[Linux Getting Started Guide](https://gitlab.com/openrsc/openrsc/-/blob/develop/Linux%20Getting%20Started%20Guide.md?ref_type=heads)**
* Consider accessing the project using **[IntelliJ IDEA](https://www.jetbrains.com/idea/download)**
